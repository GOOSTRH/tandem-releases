# Tandem releases

Built Tandem installers and update files. Tandem checks this repo to update itself.

Download the latest version from **Releases**:
- Mac (Apple Silicon M1–M4): `Tandem-x.y.z-mac-AppleSilicon.dmg`
- Mac (Intel): `Tandem-x.y.z-mac-Intel.dmg`
- Windows: `Tandem-x.y.z-windows-setup.exe`
